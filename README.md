# 学习笔记套图 · study-note-carousel

将播客逐字稿、文章或已有笔记整理为中文学习笔记套图：先忠实整理内容、区分引文与编辑补充，再写发布标题与配文、规划分页、生成完整页面，最后逐页质检并打包。

## 产出

- 完整发布文案与逐页正文
- 按数字排序的封面及内页图片；页数随内容决定
- 实际生成与返修提示词、发布顺序和制作进度，支持中断续做
- 按需要提供 ZIP；不会自动发布小红书

## 默认风格

3:4 竖版活页学习笔记：中性象牙白纸、深橄榄绿草地、银色三环与自然光；左对齐宋体标题、细宋体正文、浅绿半透明块状高亮，配有意义的极简黑线手绘概念图。长正文优先缩图，并保留独立页码区。

系列名称、编号、副标题、来源与署名均可调整。当前默认署名为 `@小沾同学`，使用者可替换。参考中的题目和 10 页总数只属于示例。

## 安装与调用

将本仓库克隆到 Codex 的技能目录：

```bash
git clone https://github.com/cinderzhan/study-note-carousel.git ~/.codex/skills/study-note-carousel
```

仓库为私有，需要当前 Git 凭据有访问权限；如果目标目录已经存在，先检查内容，不直接覆盖。设置了 `CODEX_HOME` 时，也可放到其 `skills/study-note-carousel` 目录。仓库根目录的 `SKILL.md` 是技能入口，保留 `agents/` 与 `references/` 相对路径。

调用示例：

> 使用 $study-note-carousel，把这份播客逐字稿做成一套学习笔记。沿用默认风格，署名改为 @你的名字，保存到当前项目。

使用内置 imagegen，遵循当前环境的工具规范；流程本身无需单独配置环境 API key。先落盘正文，再逐张或小批次生成。图片里的中文仍需逐页核对，尺寸检查不等于全文检查。
